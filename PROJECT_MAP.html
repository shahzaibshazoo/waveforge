10-Day Project Timeline

PHASE 1→5
1
~Day 1–2 · FDTD Engine
Built WaveForge FDTD Engine
PyTorch 3D Maxwell solver on GPU. 64³ Yee grid, Mur ABC, UWB Gaussian monocycle 0.5–1.5 GHz. Cole-Cole tissue dielectrics (Gabriel 1996). 8-element MIMO ring at 90mm. Background subtraction. DAS beamformer with layered-medium travel times. ~567 Mcells/s on T4.
✓ Engine validated — 4/4 classes physically consistent
2
~Day 2–4 · Dataset Generation
Generated WaveForge Dataset (Part 1 + Part 2)
Part 1: 1,600 train + 374 test on Kaggle (shahzaibshazoo/data-part1). Part 2: ~1,600 more samples on second Kaggle account (thamahnoor/part2), seeds 200k–300k to avoid overlap. Unique geometry per sample from population distributions. 3 blood-aging stages. Total ~3,200 train / ~748 test.
✓ Largest geometry-varied FDTD brain haemorrhage dataset
3
~Day 4–5 · Classifier v1
PhysioMIMO-Net v1 — First Results
Physics-split temporal branches (W1/W2/W3) + 2-layer MIMO Transformer + multi-task regression. Part 1 only: 79.68%. Binary classifier: 100% (proved signal quality). Combined Part1+Part2: 82.05%, ablation showed Transformer is dominant (-2.5pp without it).
✓ 82.05% on combined dataset
4
~Day 6–7 · SOTA Research + Paper
5 Research Agents — SOTA Comparison + GigaScience Draft
Deployed agents using Semantic Scholar API. Found: zero prior 4-class raw-MIMO papers, zero public FDTD brain datasets. Verified DOIs live. Wrote complete GigaScience data note in LaTeX. Discovered: Yin 2021 (only other 4-class, ~76%), Alon 2021 (binary >94%, DOI confirmed). GigaScience paper → reclassified as data supplement; main article is IEEE JBHI.
✓ No competitor exists for 4-class raw-MIMO classification
5
~Day 7–8 · v2 Architecture
PhysioMIMO-Net v2 — Cross-Window Attention + FFT Branch
Added CrossWindowEncoder (3 branches + self-attention between windows for EDH/SDH energy ratio), FrequencyEncoder (FFT magnitude CNN for spectral dura fingerprints), deepened Transformer to 4 layers, removed regression head (ablation showed +1.1pp). Fixed fp16 attention bug (mean(0) → shape error).
✓ 84.71% (+2.66pp over v1)
6
~Day 8–10 · v3 Architecture
PhysioMIMO-Net v3 — MultiScale + SupCon + TTA
Added 4th stream: MultiScaleTemporalEncoder (stride 1/2/4 CNNs). Added Supervised Contrastive Loss (temperature=0.3, weight=0.3) to push EDH/SDH embeddings apart. Added 8-way ring rotation TTA at inference. Fixed 4 fp16/NaN bugs in SupCon (temperature overflow, autocast incompatibility). Key result: EDH F1 = SDH F1 = 0.755 exactly — SupCon perfectly balanced the two hardest classes.
✓ 87.37% TTA / 86.84% std (+11.37pp over Yin 2021)

PhysioMIMO-Net Architecture

v3 FINAL

Input: raw scattered MIMO signal tensor (B, 8, 8, 700) — no DAS preprocessing. Four parallel streams, each producing a 256-dim embedding.

Input

(B, 8, 8, 700)

float32

→
Stream 1: MultiScaleTemporalEncoder

CNN stride=1 (fine) + stride=2 + stride=4 (coarse) over full 700 steps

→ 256-dim

Stream 2: CrossWindowEncoder

W1[0-150] skull/EDH · W2[50-350] SDH · W3[200-700] ICH + cross-window self-attention

→ 256-dim

Stream 3: FrequencyEncoder

rfft magnitude bins 1–200 → 1D CNN (spectral dura-layer fingerprints)

→ 256-dim

Stream 4: MIMOAttentionV2

8 antenna embeddings + geometric pos-encoding (cos/sin ring angle) → 4-layer Transformer

→ 256-dim

→
Fusion

concat(4×256)=1024

Linear(1024→512)→LN→GELU

Linear(512→256)→LN→GELU

→
Classifier Head

Linear(256→4)

CE + SupCon loss

Proj Head (training)

Linear(256→128)→L2-norm

SupCon only

Loss: CE(logits, labels, smooth=0.05) + 0.3 × SupCon(proj, labels, temp=0.3)
TTA: 8 ring rotations averaged at inference
Training: AdamW, lr=5e-4, CosineAnnealingWarmRestarts T₀=50, NO autocast
